# Toy Store Frontend (React + Vite + TypeScript)

This is a minimal React frontend using Vite and TypeScript (TSX). It fetches products from the backend API.

Commands:

```bash
cd frontend
npm install
npm run dev
```

The dev server runs on `http://localhost:5173` by default and expects the backend at `http://localhost:3000`.

You can edit the app in `src/App.tsx` and styles in `src/styles.css`.
